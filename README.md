## 📖 Description
This project was originally developed during a full-stack internship at UCSI University in Malaysia.  
It is a private, internal document search engine designed for UCSI faculty members only.  
The system allows authenticated users to search documents using keywords and filter results by file extension.  
Although the original version was lost, this version (v2.0) has been recreated from memory and rebuilt from scratch with enhancements.
